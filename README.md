# Vishwanath P Hesamani — Personal Web Portfolio

A modern, responsive, and formal web portfolio showcasing engineering projects, technical skills, and cloud security background. Built with clean HTML5, CSS3, modern JavaScript (ES6+), and Tailwind CSS.

🌐 **Live Website**: [https://vish-nath.github.io/](https://vish-nath.github.io/)

---

## 🌟 Key Features

- **Formal Light Theme**: Clean, high-contrast, professional design system built with Slate, Indigo, and Blue color palettes.
- **Dynamic Interactive Background**: Smooth HTML5 Canvas particle constellation animation with gentle mouse interaction and `prefers-reduced-motion` support.
- **Custom Gradient Cursors**: Precision SVG custom mouse cursors (Arrow & Pointer Hand) with a blue-to-purple gradient, smooth movement trailing aura, and click shockwave animations.
- **ScrollSpy Navigation**: Real-time `IntersectionObserver` navigation tracking that automatically highlights active section links as you scroll.
- **Organized Architecture**: Clean separation of structure (`index.html`), styling (`css/main.css`), logic (`js/main.js`), and media assets (`assets/images/`).
- **Interactive Contact Form**: Direct message relay powered by Formspree API.
- **Fully Responsive**: Mobile-first fluid layout optimized for smartphones, tablets, and desktop displays.

## 💻 Local Development Setup

To run or customize this portfolio locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Vish-nath/Vish-nath.github.io.git
   cd Vish-nath.github.io
   ```

2. **Serve locally**:
   You can serve `index.html` using any static local HTTP server (e.g., Live Server extension in VS Code/Android Studio, or Python built-in server):
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your web browser.
